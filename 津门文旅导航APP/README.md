# 津门文旅 Android APP

技术栈 Kotlin + Jetpack Compose。APP 为 **纯离线模式**：景点、评论、用户与全部算法均内置在 APK 中，登录 / 注册、路线规划、客流预测、情感分析、画像推荐、费用预算、安全预警全部在本机完成，**无需联网、无需启动后端**。

构建环境（本机已验证）：Android Studio 2025.3.2（JDK 21）、Gradle 9.3.1、AGP 9.1.0、Kotlin 2.2.10、compileSdk 36、minSdk 26。

## 目录结构

```
android/
  app/
    src/main/java/com/tianjin/wenlu/
      MainActivity.kt        # 入口
      WenluApp.kt            # Application：初始化本地数据与收藏/路线存储
      data/                  # 数据模型、离线数据仓库、本地会话/收藏存储
      ApiClient.kt           # 网络层保留（当前纯离线模式不发起请求）
      ui/
        WenluApp.kt          # 导航（登录/主框架/详情/预算/设置/我的路线/收藏）
        screens/             # 登录、首页、景点列表/详情、路线规划、推荐、预算、我的等
        components/          # 公共组件（加载/错误/指标卡/标签）
        theme/               # 主题色（沿用 Web 端深蓝视觉）
```

## 构建与安装

### 方式一：Android Studio（推荐）

1. 用 Android Studio 打开本目录（android/）；
2. 等待 Gradle 同步完成，连接真机或启动模拟器；
3. 运行 app 配置（Debug）。

### 方式二：命令行

```powershell
# 使用 Android Studio 自带 JDK 21
$env:JAVA_HOME = "D:\Android\Android Studio\jbr"
cd android
.\gradlew.bat :app:assembleDebug
```

APK 输出：app/build/outputs/apk/debug/app-debug.apk（Debug 包名带 .debug 后缀：com.tianjin.wenlu.debug）

1. 登录 demo / 123456（游客，账号校验在本地完成）；
